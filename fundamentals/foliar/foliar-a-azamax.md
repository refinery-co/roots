# Foliar Spray A — Azamax

**Frequency:** Every 2 weeks — alternate with Foliar B (Spinosad)
**Per:** 1 gallon

---

## Mix Order — Add in This Sequence

| Ingredient | 1 gal | 32 oz | 16 oz |
|---|---|---|---|
| TPS Silica Gold | 8ml | 2ml | 1ml |
| **— WAIT 30 MINUTES —** | | | |
| Bloom City Clean Kelp | 8ml | 2ml | 1ml |
| Foliage Pro 9-3-6 | 1ml | 3–4 drops | 1–2 drops |
| GH Azamax | 15–30ml | 4–8ml | 2–4ml |
| Peppermint Soap | 3–4 drops | 1 drop | 1 drop |

**pH target:** 6.0–6.5

**Practical batch size:** 32oz is the recommended minimum. Foliage Pro and peppermint soap are hard to measure accurately below that. Mix only what you'll use — Azamax solution is good for 24–48 hours covered and out of light, but kelp degrades after 24 hours so don't store longer than that.

---

## How It Works

| | |
|---|---|
| Mode of action | IGR — disrupts insect molting + antifeedant |
| Best against | Thrips larvae, broad mites, fungus gnats |
| Systemic? | Partial — absorbed through leaf tissue |
| Reapply cycle | Every 7–10 days, minimum 2–3 cycles |
| OMRI listed | Yes — safe for indoor/greenhouse use |

---

## Notes

- Evenings only — spray all surfaces including undersides — low light only
- Next spray session switch to Foliar B (Spinosad) to prevent resistance
- Source: GH AzaMax label — 0.5–1.0 oz (15–30ml) per gallon confirmed
