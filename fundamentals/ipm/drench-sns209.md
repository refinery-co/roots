# IPM Root Drench — SNS 209

**Add to every regular watering — per 1 gallon**

---

## Mix

| Ingredient | Amount |
|---|---|
| SNS 209 Concentrate | 8ml (1/4 oz) |

**pH target:** 6.0

---

## Usage + Notes

| | |
|---|---|
| Active ingredient | Rosemary oil — rosmarinic acid |
| Mode of action | Systemic via roots — makes plant unpalatable to pests |
| When to use | Every regular watering as preventative drench |
| OMRI listed | Yes — approved for organic production |
| Limitations | Preventative only — does not resolve active infestation |
| Active infestation | Use Azamax drench (15ml/gal) every 7 days × 3 for gnats |

Preventative only — if pests are established use Azamax drench or Safari 20SG systemic.
