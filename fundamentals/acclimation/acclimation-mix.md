# Acclimation Mix

**New arrivals — weeks 1–2 — no fertilizer — per 1 gallon**

---

## Mix Order — Add in This Sequence

| Ingredient | Amount |
|---|---|
| Tap Conditioner | 0.1ml |
| TPS Silica Gold | 3ml |
| **— WAIT 30 MINUTES —** | |
| Bloom City Kelp | 5ml |
| GH Rapidstart | 2ml |
| Hydroguard | 2ml (fresh — never bulk) |
| Microbe Life FGX | 1.5ml (fresh — never bulk) |
| Orca | 2ml (fresh — never bulk) |
| SNS 209 | 8ml |

**pH target:** 6.0

---

## Why Each Ingredient

| Ingredient | Role |
|---|---|
| TPS Silica Gold | Silica on cell walls — physical pest + stress barrier |
| Bloom City Kelp | Cytokinins + auxins — ease stress, stimulate roots |
| GH Rapidstart | IBA root hormone — fastest route to new root growth |
| Hydroguard | *B. amyloliquefaciens* — biofilm protects stressed roots |
| Microbe Life FGX | Broad microbial inoculant — builds root zone biology |
| Orca | Liquid mycorrhizae — direct root inoculation |
| SNS 209 | Rosemary oil systemic — pest deterrent via roots |

---

## Why No MSU

No MSU, no CALiMAGic — feeding stresses already-stressed roots. Newly shipped plants are pest targets — silica + SNS 209 close that window. Nutrition starts week 3 (Day 14+) only if the plant looks healthy.
