## Philosophy

Protocols here are built on mechanism, not habit. Every recommendation traces back to a source — a label, a study, a collector with documented results. When sources conflict, the more conservative, plant-physiology-grounded position wins until evidence says otherwise.

The Taleb principle applies: optimize for not losing a plant before optimizing for maximum growth. A dead collector specimen is a permanent loss. An extra week of acclimation costs nothing.
