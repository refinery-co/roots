## Approach

> Optimize for not losing a plant before optimizing for maximum growth. A dead collector specimen is a permanent loss. An extra week of acclimation costs nothing.

Sources conflict. Labels are sometimes wrong. When that happens, the more conservative, plant-physiology-grounded position holds until evidence says otherwise.
