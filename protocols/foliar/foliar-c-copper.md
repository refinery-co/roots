# Foliar Spray C — Copper Fungicide

**Frequency:** Every 3–4 weeks (preventative)
**Per:** 1 gallon
**⚠ STANDALONE ONLY — read rules before mixing**

---

## Mix

| Ingredient | Amount |
|---|---|
| Bonide Liquid Copper Fungicide | 15–30ml (0.5–1 oz) |

**pH target:** 6.5–7.0 (higher than other sprays)

---

## Rules — Read Before Mixing

| | |
|---|---|
| Prevents | Fungal + bacterial disease on leaves |
| Frequency | Every 3–4 weeks as preventative |
| **NEVER mix with** | **Azamax, Spinosad, or any biological** |
| **NEVER mix with** | **Hydroguard, Recharge, FGX, or kelp** |
| After copper | Wait 48 hours before any biological application |

Copper kills beneficial fungi and bacteria. Standalone session only — no stack.

---

## Notes

- Standalone session only
- Source: Bonide Liquid Copper Fungicide label — 0.5–2.0 oz per gallon ornamentals
